## 📅 Day 4 — LeetCode  Problems

### ✅ Q12 — Find managers with at least 5 direct reports

**Source:** LeetCode  
**Requirement:** From the Employee table, find the names of employees who manage at least 5 other employees directly.

**Table Setup:**
```sql
CREATE TABLE Employee (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    department VARCHAR(10),
    managerId INT
);

INSERT INTO Employee (id, name, department, managerId) VALUES
(101, 'John',  'A', NULL),
(102, 'Dan',   'A', 101),
(103, 'James', 'A', 101),
(104, 'Amy',   'A', 101),
(105, 'Anne',  'A', 101),
(106, 'Ron',   'B', 101);
```

**Solution:**
```sql
SELECT name FROM Employee
WHERE id IN (
    SELECT managerId FROM Employee
    GROUP BY managerId
    HAVING COUNT(managerId) >= 5
);
```

> 💡 Key concept: Subquery groups by managerId and counts how many employees report to each manager. Outer query fetches the name of those managers using IN.
